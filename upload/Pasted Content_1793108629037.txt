# 14. Animation & Interaction System

Animations should be elegant and subtle.

## Motion Principles

- Animate only when movement improves visual clarity
- Prefer opacity and transform
- Avoid layout-shifting animations
- Keep animation duration mostly between 200ms and 650ms
- Use consistent easing
- Respect prefers-reduced-motion
- Avoid animation on every small element

### Recommended Animations

**Hero**
- Staggered text reveal
- Gentle portrait appearance
- Refined CTA appearance

**Scroll sections**
- Fade upward 12–24px
- Once on viewport entry
- No excessive stagger

**Project cards**
- 2–4px hover lift
- Subtle border transition
- Minimal image zoom
- Small arrow translation

**Navigation**
- Animated active indicator
- Smooth hover transitions
- Understated scroll appearance

**Buttons**
- Background/color transition
- Arrow movement by a few pixels
- Clear keyboard focus state

**Timeline**
- Subtle marker appearance
- Light fade-in

### Animation Restrictions

Do not implement:
- Large floating spheres
- Excessive parallax
- Random particles
- Neon glow
- Glitch effects
- Heavy three-dimensional animations
- Scroll hijacking
- Large magnetic cursors
- Constantly rotating elements
- Overcomplicated page transitions
- Fake terminal typing as the primary hero

The site must remain pleasant during long browsing sessions.
